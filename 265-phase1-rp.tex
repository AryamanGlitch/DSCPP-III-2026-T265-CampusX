\bluebigheading{PROPOSAL DESCRIPTION}

\vspace{12mm}

\blueheading{Motivation}

\vspace{1mm}



\answerbox[5cm]{We wish to build Campus X because we believe that college life can be more organized and connected with a single platform. Our main goal is to create something that students can use every day. Campus X will bring together activities like announcements, events, clubs, academic resources, student connections, Lost and Found emergency updates, all in one place. We want students to find what they need easily without having to check groups or sources. We want this project to be practical and meaningful for our learning. Since we are studying Data Structures and OOP in C++, it gives us a chance to apply what we learn. We can use these concepts to build a working system that solves problems. This helps us understa how the theory we learn can be used to create something.}

\vspace{12mm}

\blueheading{State of the Art / Current solution}

\vspace{1mm}



\answerbox[6cm]{Currently college-related information is mreceived by platforms instead of a unified system. WhatsApp groups are often used for announcements, discussions, notes and event updates. Instagram pages are used by clubs and societies to promote events and activities. Official information is usually shared through the college website, notice boards or separate communication channels. Students therefore have to check multiple sources depending on what information they need.
\vspace{2mm}

Although these methods are helpful, they can make campus information tedious to access. Important updates can get lost in group conversations. Some student-focused platforms offer features like communities, events, and student connections. They are not specifically built around the needs of our college. Campus X aims to bring all these activities in one organized platform. It will use DSA based solutions, for searching, recommendations, ranking, notifications and information management.}

\vspace{12mm}
\newpage

\blueheading{Project Goals and Milestones}

\vspace{1mm}


\answerbox[20cm]{Our primary goal is to develop a platform for students to help them share information, connect with other student, and access academic and campus related resources. we will use heaps, priority queues, and trees to manage data efficiently. Whilst making use of the OOP concepts learned through C++.
The main goals are:

\begin{itemize}
    \item Managing posts, announcements, events, clubs, and resources
    \item Providing friend and project partner recommendations
    \item Ranking content using popularity, relevance, importance, and recency
    \item Handling spam, duplicates, deleted posts, blocked users, and outdated information
\end{itemize}

Data Structures and Algorithms will form the core of the system:

\begin{itemize}
    \item \textbf{Hashing:} Duplicate detection and fast data access
    \item \textbf{Graph:} Friend and project partner recommendations
    \item \textbf{Priority Queue:} Emergency and important notifications
    \item \textbf{Trie:} Efficient searching
    \item \textbf{Queue and Stack:} Ordered and recent operations
    \item \textbf{Sorting and Searching:} Ranking and retrieving data
\end{itemize}

Object-Oriented Programming will be used to organize the system into manageable classes and modules.\\

\textbf{Planned Milestones:}

\begin{itemize}
    \item \textbf{Phase 1 -- Planning:} Finalize requirements, workflow, classes, and system design.
    \item Identify suitable Data Structures and Algorithms for each feature.
    \item \textbf{Phase 2 -- Development:} Implement the required DSA concepts and core Campus X modules in C++.
    \item Integrate posts, profiles, events, resources, recommendations, and notifications.
    \item \textbf{Phase 3 -- Testing:} Integrate the complete system and test all major features and edge cases.
    \item Optimize the algorithms and prepare the final demonstration.
\end{itemize}}

\vspace{12mm}
\newpage

\blueheading{Project Approach}

\vspace{1mm}





\answerbox[14cm]{\begin{enumerate}
    \item Requirement Analysis and Planning -- Find what Campus X needs and set up how profiles, posts, announcements, events, clubs, resources, notifications, and recommendations will work together.

    \item Data Structure Design -- Designing the data structures to represent the required data using hash tables, graphs, trees, queues, stacks, priority queues, etc.

    \item Post and coontent Management -- Develop a post system that allows posting, deleting, and sorting through the posts. Implement hash tables to check whether a post already exists or not. Apply data structure concept to store and manage the content.

    \item Recommendation System and search feature-- Implementing searching using Trees. Use graphs to suggest friends and project partners based on connections and similar interests

    \item Ranking System -- Rank content based on popularity, relevance, importance. Use Priority Queue to ensure urgent and important notifications pop up first

    \item Exception Handling -- Handle real-life cases such as repeated spam messges, blocked users, deleted posts and outdated information

    \item Integration and testing of module -- Combine all the modules into the Campus X application and test normal operations along with different edge cases

    \item Performance analysing -- Analyze the speed, memory used, and efficiency of the implemented Data Structures and Algorithms and improve the system wherever it is\textbf{} required
\end{enumerate}}

\blueheading{Project Outcome / Deliverables }

\vspace{1mm}

\answerbox[13cm]{our main goal with this project is to develop a platform that is designed specially for college students.

\begin{itemize}[leftmargin=*,itemsep=2pt]

    \item It will allow efficient searching, clubs, events, resources and campus information using tree and hashing

    \item It will connect students through communities and recommendation system will be built using Graphs and BFS

    \item It will manage resources and Lost \& Found information with efficient searching and duplicate detection

    \item It  will manage events, notifications and emergency updates using queues and priority queues

    \item It will support Trending and campus leader board features using heaps and priority queues

    \item It will organizee departments, batches and clubs using tree structures
